SITE MAËVA — ORGANISATION DES MÉDIAS

Structure :
- index.html à la racine
- photos/ : toutes les photos et images
- videos/ : toutes les vidéos
- musique/ : tous les fichiers audio

Les chemins dans index.html ont été adaptés à cette nouvelle organisation.

Pour GitHub Pages :
1. Garder index.html à la racine du dépôt.
2. Créer les dossiers photos, videos et musique.
3. Téléverser les fichiers contenus dans chaque dossier.
4. Utiliser la branche main.
